# Applied Machine Learning (AML-Advanced)

> B5779 · Period 1 · Type C · PHYS-01/A · 9 CFU · Gruppo Bioinformatics

> [!info] Modulo di [[Applied Machine Learning]]


## Lectures

Docente: Luca Clissa (AML-Advanced).

- Decision Trees, Ensemble Learning, SVM
- Reti neurali: MLP, tensori, TensorFlow/Keras, TensorFlow Playground
- CNN (storia, feature map, filtri), Autoencoders
- RNN, LSTM, GRU
- Training di reti profonde: vanishing/exploding gradient, batch normalization
- NLP, Transformers, LLM
- MLOps, Interpretability & Explainability (XAI)
- Cenni di Quantum Machine Learning
- Hands-on su dataset benchmark (IRIS, MNIST) per ciascun argomento
