# Applied Machine Learning (AML-Basic)

> B5779 · Period 1 · Type C · PHYS-01/A · 9 CFU · Gruppo Bioinformatics

> [!info] Modulo di [[Applied Machine Learning]]

## Lectures

Docente: Daniele Bonacorsi (AML-Basic).

- Definizioni e tipi di Machine Learning
- Regressione lineare uni/multivariata, cost function, gradient descent, learning rate
- Feature scaling/standardizzazione/normalizzazione, regressione polinomiale, normal equation
- Classificazione: hypothesis representation, decision boundary, regressione logistica, multiclasse
- Overfitting, regolarizzazione
- Model selection: train/validation/test, cross-validation, bias vs variance, learning curve
- Metriche per classi sbilanciate: confusion matrix, precision, recall, F1, ROC, AUC
- Hands-on: Jupyter/Colab, preparazione dataset, feature selection, tuning
