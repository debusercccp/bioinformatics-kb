## Python Data Structures – Built-in Options

When you create data you can choose how to structure them:

> ***Lists*** → **Ordered**, **flexible**, **allows** **duplicates**
>
> ***Dictionaries*** → **Key-value pairs**, **fast lookups (ricerche rapide) *Sets*** → **Unordered**, **unique** **elements**

But also you can use third party libraries to structure them into array:

> ***NumPy*** → **math-like arrays**

So you have to choose the right one when you perform an analysis:

Need order, flexible (shape, type) collections?

→ List

Fast lookups, meaningful index?

→ Dict

Uniqueness, easy to compare?

→ Set

Math operations, efficient?

→ NumPy

The right chose in variabile type can has effect into **speed & memory efficiency impacting machine learning performance** but also in **readability & ease of use** that matter in realworld coding.
