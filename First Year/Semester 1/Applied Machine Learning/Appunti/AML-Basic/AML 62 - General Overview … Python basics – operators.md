# General Overview

- Python is a general-purpose, **interpreted programming language**

- It is easy to read and write, with a **syntax similar to pseudo-code**

- Python is widely used in **scientific computing**, including bioinformatics and data science **Key Features**

- It is **Readable & Compact** – Code looks like an English description • **Versatile & Forgiving** – Quick coding, easy debugging

- Strong Community & Ecosystem:

> •**Large collection of libraries** (e.g., NumPy, Pandas)
>
> •Documentation, tutorials, forums

- **Indentation-based Syntax** – No curly braces {} like in C

## Python Basics: syntax, types and control structures

> Simple & Readable Syntax:

- ![[AML-image403.jpg|311]]No semicolons, **indentation matters** Interpreted Language:

> Basic Data Types:
