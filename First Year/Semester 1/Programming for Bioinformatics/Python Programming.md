# Python Programming

> D0526 · Period 1 · Type C · INFO-01/A · 6 CFU · Gruppo Bioinformatics (I.C.)

> [!info] Modulo di [[Programming for Bioinformatics]]

## Lectures

Docente: Ivan Lanese. Dal 29/10/2026 al 21/12/2026.

Il corso è composto da 2 moduli:
1. Programmazione Python: variabili, espressioni e istruzioni, funzioni, condizionali, iterazione, stringhe, liste, tuple, dizionari, file, ricorsione, programmazione orientata agli oggetti
2. Supporto allo sviluppo di pipeline bioinformatiche in Python: librerie dedicate, formati file biologici, algoritmi bioinformatici di base

Lezioni teoriche + attività pratica di programmazione in Python su Linux (editor a scelta tra EMACS, VS Code, PyCharm). Richiesta partecipazione preliminare ai Moduli 1-2 sulle norme di sicurezza nei luoghi di studio (e-learning).

## Exam

**Scritto (pratico).** Esame composto da due parti (una per modulo), anche sostenibili in appelli diversi. Ogni parte è un esercizio di programmazione Python (incluso debugging), con breve discussione del codice sviluppato. Ogni parte vale fino a 16 punti, con 1 punto bonus possibile presentando un esercizio durante il corso. Uso di IA vietato: qualsiasi utilizzo costituisce violazione dell'integrità accademica.
